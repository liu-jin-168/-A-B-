# -A-B-
项目背景：某在线书店验证深色主题是否可以提升用户业务指标，将用户随机划分为对照组（浅色）与实验组（深色）开展 A/B 测试。
数据清洗：校验缺失、重复、异常数据，保障实验数据质量。 分组统计：统计两组点击率、转化率、跳出率、会话时长、购买率、加购率等核心业务指标。
统计显著性检验：连续指标采用独立样本 t 检验，二分类指标使用卡方检验，引入 Cohen's d 评估效应量大小。
分析结论：实验组点击率显著高于对照组 (26.45% vs 24.71%, p=0.048)，但是效应量很小；转化率、购买率等核心指标无显著差异。
业务建议：不建议仅凭点击率提升就全量上线深色主题；建议结合用户画像细分分析或者扩大样本继续验证。
